# 04 — Code Reading Gym

Reading code precisely is the highest-leverage skill gap between junior and mid-level, and it's directly tested in interviews (code-review rounds, "walk me through this function," debugging screens). This module is pure reps:

1. [01-annotation-drills.md](01-annotation-drills.md) — 8 real excerpts; annotate inputs/invariants/side-effects/failure modes.
2. [02-trace-tables.md](02-trace-tables.md) — 5 traces; follow a value through the system, step by step.
3. [03-fake-code-contrasts.md](03-fake-code-contrasts.md) — 8 bad-vs-better pairs exposing novice instincts, tied to real repo patterns.
4. [04-review-katas.md](04-review-katas.md) — 8 fake PRs to review; findings graded blocking/important/optional.

Do them with a notebook, not passively. Timing guide: one annotation drill or trace table per sitting (25–40 min); one kata per sitting (30 min including writing the review).
