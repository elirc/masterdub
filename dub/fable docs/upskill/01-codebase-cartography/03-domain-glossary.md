# Domain Glossary

Product nouns, where they live, and the traps in their naming. Multi-word searches in this repo fail when you use the UI word instead of the code word — this table is the translation layer.

| Term | Meaning | Code location | Trap |
| --- | --- | --- | --- |
| **Workspace** | The tenant: a team account owning links, domains, members, plan | Prisma model is **`Project`** ([workspace.prisma](../../../packages/prisma/schema/workspace.prisma)); API/UI say "workspace"; ids are `ws_`-prefixed and normalized at [workspace-id.ts](../../../apps/web/lib/api/workspaces/workspace-id.ts) | `projectId` in the schema = workspaceId in the API. The rename never reached the DB. |
| **Link** | A short link: `(domain, key) → url` plus targeting/tracking config | [link.prisma](../../../packages/prisma/schema/link.prisma), domain logic in [lib/api/links/](../../../apps/web/lib/api/links/) | `shortLink` is the *full URL string* column; `key` is just the path part. `_root` is the reserved key for the bare domain ([link.ts#L60-L63](../../../apps/web/lib/middleware/link.ts#L60-L63)). |
| **Key** | The slug after the domain (`dub.sh/<key>`) | normalized at [link.ts#L46-L63](../../../apps/web/lib/middleware/link.ts#L46-L63) | case-insensitive by default, **per-domain** opt-out ([case-sensitivity.ts](../../../apps/web/lib/api/links/case-sensitivity.ts)); a trailing `+` means inspect mode, `.php` keys are rejected as bot bait ([link.ts#L73-L83](../../../apps/web/lib/middleware/link.ts#L73-L83)) |
| **Domain** | A customer's short-link hostname registered in a workspace | [domain.prisma](../../../packages/prisma/schema/domain.prisma), [lib/api/domains/](../../../apps/web/lib/api/domains/) | "Dub domains" (`dub.sh`, `d.to`, `buff.ly`…) are shared/public and special-cased via `isDubDomain` |
| **Click** | A recorded redirect event (deduped 1/hour per visitor+link) | [record-click.ts](../../../apps/web/lib/tinybird/record-click.ts); stored in Tinybird `dub_click_events` | a browser hit ≠ a click: bots, dedup, `dub-no-track`, and password failures all suppress recording |
| **clickId / dub_id** | The identity that joins a click to later conversions | cookie set at [link.ts#L254-L279](../../../apps/web/lib/middleware/link.ts#L254-L279); 5-min Redis cache [record-click.ts#L171-L175](../../../apps/web/lib/tinybird/record-click.ts#L171-L175) | two representations: cookie (browser) and `clickIdCache` (server) — conversions can arrive via either |
| **Lead / Sale / Conversion** | Conversion events attributed to a click | [app/(ee)/api/track/](../../../apps/web/app/(ee)/api/track/), [lib/api/conversions/](../../../apps/web/lib/api/conversions/) | `conversions` counter on Link counts *leads that converted to sales* (see comment [link.prisma#L59](../../../packages/prisma/schema/link.prisma#L59)) — not all conversions |
| **Customer** | The end-user of a Dub customer, created by conversion tracking | [customer.prisma](../../../packages/prisma/schema/customer.prisma), [lib/customers/](../../../apps/web/lib/customers/) | `customerExternalId` (their id) vs `customerId` (Dub's id) — deprecated aliases handled at [track/lead route](../../../apps/web/app/(ee)/api/track/lead/route.ts#L17-L21) |
| **Program** | A partner/affiliate program owned by a workspace | [program.prisma](../../../packages/prisma/schema/program.prisma), `(ee)` surface | one *default* program per workspace (`getDefaultProgramIdOrThrow`) |
| **Partner** | An affiliate enrolled in programs; has own portal (`partners.dub.co`) | [partner.prisma](../../../packages/prisma/schema/partner.prisma) | a partner **spans workspaces** — it's a top-level identity, not tenant-scoped; enrollment is the join (`ProgramEnrollment`) |
| **Partner link** | A link with `programId + partnerId` — attribution + payouts flow through it | detection at [link.ts#L86](../../../apps/web/lib/middleware/link.ts#L86); enrollment info cached with the link | partner links skip normal caching until enrollment info is fetched ([link.ts#L112-L131](../../../apps/web/lib/middleware/link.ts#L112-L131)) |
| **Folder** | Intra-workspace grouping of links **with its own ACLs** | [folder.prisma](../../../packages/prisma/schema/folder.prisma), [lib/folder/permissions.ts](../../../apps/web/lib/folder/permissions.ts) | folders are an *authorization* boundary, not just organization — `verifyFolderAccess` appears in read paths ([analytics route L94-L101](../../../apps/web/app/api/analytics/route.ts#L94-L101)) |
| **Tag** | Label on links, workspace-scoped | [tag.prisma](../../../packages/prisma/schema/tag.prisma) | three input forms accepted: `tagId`, `tagIds`, `tagNames` — merged by [combine-tag-ids.ts](../../../apps/web/lib/api/tags/combine-tag-ids.ts) |
| **Dashboard** (entity) | A *public stats page* for a link (`publicStats`) | [dashboard.prisma](../../../packages/prisma/schema/dashboard.prisma), created inline at [create-link.ts#L121-L130](../../../apps/web/lib/api/links/create-link.ts#L121-L130) | not the app dashboard! `Dashboard` the model = shareable analytics page |
| **Restricted token** | Workspace API key, `dub_` prefix, scoped | [token.prisma](../../../packages/prisma/schema/token.prisma), [workspace.ts#L120](../../../apps/web/lib/auth/workspace.ts#L120) | contrast with legacy personal `Token` — two tables, one auth path |
| **Machine user** | Non-human user owning integration-created resources | `isMachine` on User; auto-owner at [workspace.ts#L404-L408](../../../apps/web/lib/auth/workspace.ts#L404-L408) | force-promoted to `owner` role — surprising and security-relevant |
| **Usage / usageLimit** | Billing counters on workspace (clicks usage, links count) | `Project.usage`, incremented via Redis streams w/ SQL fallback ([record-click.ts#L202-L214](../../../apps/web/lib/tinybird/record-click.ts#L202-L214)) | "usage" unqualified = *clicks* usage; links have `linksUsage` separately |
| **Inspect mode** | Append `+` to any short link to preview instead of redirect | [link.ts#L54-L58](../../../apps/web/lib/middleware/link.ts#L54-L58), [#L175-L185](../../../apps/web/lib/middleware/link.ts#L175-L185) | blocked for password-protected links |
| **Cloaking / rewrite** | Serve destination content under the short URL (iframe/rewrite) instead of redirecting | `rewrite` flag; [link.ts#L371-L407](../../../apps/web/lib/middleware/link.ts#L371-L407) | "rewrite" in Next.js middleware ≠ the Link.rewrite feature — same word, two meanings, same file |
| **Proxy (OG proxy)** | Serve custom OG tags to bots while humans get redirected | `proxy` flag; bot branch [link.ts#L320-L333](../../../apps/web/lib/middleware/link.ts#L320-L333) | third meaning of "serving something else" — keep proxy/cloaking/inspect distinct |
| **MEGA workspace** | Workspace above a link-count threshold; gets degraded UX (exact search, no archived) | `MEGA_WORKSPACE_LINKS_LIMIT` ([links route L35](../../../apps/web/app/api/links/route.ts#L35), [use-links.ts#L36-L40](../../../apps/web/lib/swr/use-links.ts#L36-L40)) | scale tiers encoded in product behavior |

Near-synonym traps to rehearse: **Project=Workspace**; **Dashboard(model)=public stats page**; **rewrite(flag)≠rewrite(Next)**; **conversion(counter)≠conversion(event)**; **usage=clicks-usage**.
