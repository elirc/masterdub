# 06 — Contribution Practice

Knowledge becomes skill when you change the system. Three difficulty tiers plus design katas:

1. [01-good-first-tickets.md](01-good-first-tickets.md) — 16 junior tickets (hours each, small blast radius).
2. [02-mid-level-feature-tickets.md](02-mid-level-feature-tickets.md) — 10 cross-layer tickets requiring design notes before code.
3. [03-senior-build-projects.md](03-senior-build-projects.md) — 6 projects (days–weeks) with full design checklists.
4. [04-refactor-and-design-katas.md](04-refactor-and-design-katas.md) — 8 senior katas, self-graded.

Every ticket carries an **Interview story potential** line — completing even three of these gives you the concrete STAR material that most candidates lack ([08/06](../08-interview-prep/06-behavioral-star-stories.md)).

House rules: work on branches; never point tests at production; before proposing anything upstream, open an issue first and follow [07/03-maintainer-communication.md](../07-career-and-collaboration/03-maintainer-communication.md). Do the design note *before* the code on every tier-2+ ticket — the note is half the learning.
