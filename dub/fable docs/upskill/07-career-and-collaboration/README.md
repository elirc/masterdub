# 07 — Career and Collaboration

Mid-level is a *collaboration* promotion as much as a technical one: you review others' code, write PRs that get merged without three rounds of confusion, and communicate with people who owe you nothing (OSS maintainers being the purest training ground).

1. [01-code-review-mindset.md](01-code-review-mindset.md) — the review layers + a repo-specific checklist + example comments.
2. [02-writing-prs-and-rfcs.md](02-writing-prs-and-rfcs.md) — PR descriptions, commit messages, when and how to RFC.
3. [03-maintainer-communication.md](03-maintainer-communication.md) — asking, proposing, reporting, disagreeing; with templates.

These skills are examined directly in behavioral interviews ("tell me about a code review conflict") and indirectly everywhere else — the candidate who writes a clear design note in a system-design round is running this module's playbook.
